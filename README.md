

SPA-портал для разработчиков с 5 основными разделами:

1. **Главная** (`#/`) — hero-блок с поиском, топ-6 репозиториев и превью 4 утилит.
2. **GitHub** (`#/github`) — каталог репозиториев с фильтрами, сортировкой, категориями и избранным.
3. **Языки** (`#/languages`) — карточки 14 языков с ссылками на официальные ресурсы.
4. **Утилиты** (`#/tools`) — 8 онлайн-инструментов (Base64, JWT, хеши, конвертеры цветов/валют/единиц/JSON→YAML/часовых поясов).
5. **Загрузка ПО** (`#/software`) — таблица официальных источников для Windows/Office/VS/SQL Server.

- Нулевые зависимости, всё на vanilla JS
- Хеш-роутинг без History API
- Глобальный поиск через нативный `<dialog>` и `Ctrl+K`
- Web Crypto API для SHA-хеширования
- Полная поддержка тёмной/светлой темы через CSS custom properties и `prefers-color-scheme`
- Локализация через словарь `T = { ru: {...}, en: {...} }`
- Сохранение состояния в `localStorage` (тема, язык, избранное)
